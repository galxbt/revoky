# 🔐 Revoky

Revoky is a **Wallet Risk Intelligence Layer for Web3**.

It scans wallets across multiple chains, detects risky token & NFT approvals, explains exposure, and lets users revoke them safely.

---

## ⚡ Core

- Multi-chain approval scanning
- Risk scoring + human-readable insights
- Wallet exposure breakdown
- Batch revoke engine

---

## 🛠 Tech

React (Vite) • Ethers.js • Viem • Multicall • Express.js • Blockscout • Injected Wallets

---

## 🚀 Run

```bash
git clone https://github.com/TheBoredDev01/revoky.git
cd revoky
npm install
npm run dev
```
